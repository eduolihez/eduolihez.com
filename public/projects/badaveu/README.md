# 🏛️ BadaVeu (Smart City Badalona)

**BadaVeu** es una plataforma GovTech de código abierto (Progressive Web App) diseñada para transformar la gestión de incidencias urbanas en Badalona. Permite a los ciudadanos reportar problemas en la vía pública de forma rápida, geolocalizada e intuitiva.

Más allá de ser un buzón de quejas, la plataforma actúa como un **escaparate de eficiencia municipal**, proporcionando a los administradores mapas de calor y métricas SLA para optimizar recursos.

## 🚀 Características Principales
- **Map-First UI:** Interfaz basada en Leaflet para una geolocalización precisa.
- **Geocodificación Inteligente:** Integración con Nominatim (OSM) y extracción de metadatos EXIF de fotografías para ubicar automáticamente la incidencia.
- **Validación Comunitaria:** Sistema de votos ("A mí también") para evitar reportes duplicados.
- **Centro de Mando (Admin):** Mapas de calor y gestión de estados de incidencias.
- **Seguridad Robusta:** Backend en PHP 8 con PDO (Prepared Statements), mitigación XSS y validación de archivos.

## 🛠️ Stack Tecnológico
- **Frontend:** HTML5, CSS3 (Mobile-First), Vanilla JavaScript.
- **Librerías:** Leaflet.js, EXIF.js, SweetAlert2.
- **Backend:** PHP (API RESTful).
- **Base de Datos:** MySQL / MariaDB.
